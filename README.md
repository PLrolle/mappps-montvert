# MAPPPS — Pilotage du mandat, démonstrateur Montvert-sur-Marne

Démonstrateur d'un portail de pilotage pour une commune **fictive**. La commune, les personnes et toutes les données sont inventées.

Quatre écrans :

- `index.html` : la note hebdomadaire de la DGS à la maire ;
- `decisions.html` : les décisions relevées dans les comptes rendus, à valider par la direction de projet ;
- `portefeuille.html` : le portefeuille des projets du plan de mandat ;
- `engagements.html` : la page publique des engagements, pour les habitants.

Le site est statique : du HTML, un petit moteur de rendu sans dépendance (`dc-lite.js`) et la police Satoshi. Il s'ouvre dans n'importe quel navigateur, y compris hors ligne. Les données affichées sont une copie de la base de pilotage Grist du démonstrateur.
